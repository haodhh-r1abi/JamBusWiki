Localization — text UI (48 file .lan)

Localization — text UI (48 file .lan) · nguồn appendix/localization.md

Nguồn: assets_dec/*.lan — plist XML (lans + mảng localization gồm {key: {ngôn ngữ: text}}); file cờ «n» trong mainData được lưu thường (không RC4) — jb_decrypt.py đã sửa ngày 15/11. Bảng đầy đủ: localization.tsv (1245 dòng × 20 ngôn ngữ, cột gdd = tính năng). Sinh bởi tools/jb_localization.py.

Tóm tắt

  • 48 file, 1245 khoá text; 0 file đọc lỗi.
  • 12 ngôn ngữ chuẩn: en, zh-Hans, zh-Hant, es, pt, fr, de, it, ru, ja, ko, ar. Không có tiếng Việt trừ 2 file (金片活动, 魔药课) khai báo thêm vi/id/th/ms — 39 khoá có ô vi, 39 ô vi khác rỗng.
  • Tên khoá mang tiền tố module của khung template (M8P_ = meta m8, OSG_ = vòng chơi m8, GU_ = lõi Bus, YJ_ = bàn xe kiểu Parking Jam), giúp nối text với layout .redream cùng tên.
