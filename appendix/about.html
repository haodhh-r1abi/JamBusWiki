Về tài liệu này

Nguồn dữ liệu

  • APK Jam Bus: Sandfall build 41.0 (bus.sand.fall.jam.loop.traffic.flow, Android arm64-v8a). Engine Cocos2d-x 3.16: toàn bộ logic game là C++ trong libMyGame.so (không có IL2CPP / dump.cs). Thư viện còn ~103.700 symbol C++ trong .dynsym nên tên lớp/hàm là tên thật (BusQueue::*, CCubeBox, SandPainting, m8*, actlib::*, guild::*, RedIAP::IAP…); Ghidra decompile các hàm game thành pseudo-C, một file một lớp (pseudoc/<Class>.c, danh mục facts/classes.json).
  • Tài nguyên: ~11.150 file trong assets/bin/Data/ mang tên MD5 và bị mã hoá RC4 (khoá = package name, biến thể không reset j sau KSA); bảng tên gốc nằm trong mainData (protobuf, cũng RC4). Tất cả đã giải mã (và inflate khi là zlib) vào assets_dec/ với tên gốc: config JSON/CSV tiếng Trung, 297 file level configs_level*.json, bảng sinh xe configs_ballData-*.json, tranh cát sandPic_*, UI Redream (.redream/.redpb), atlas TexturePacker (.plist + .webp) — icon trên site cắt từ các atlas này.
  • Snapshot thiết bị ngày 13/11/2026 (cài mới, level 1, LDPlayer): MMKV cocos_data_default / progress_sync, Cocos2dxPrefsFile, Firebase Remote Config đã kích hoạt. Không gửi request nào tới server game; không có playtest ở level cao.
  • Chi tiết pipeline (giải mã, Ghidra, symbol): PLAN.md ở thư mục export.

Nhãn bằng chứng trong mục Thiết kế chi tiết

  • Code Đọc từ pseudo-C của libMyGame.so build 41.0 (Ghidra, tên lớp/hàm thật từ symbol C++)
  • APK Giá trị trong tài nguyên APK đã giải mã RC4 (assets_dec: JSON / CSV / level / const)
  • Live 13/11 Snapshot thiết bị ngày 13/11/2026 (MMKV, prefs, Firebase Remote Config)
  • Playtest Thấy khi chơi thật (có ảnh chụp làm bằng chứng)
  • Nhận định Suy luận thiết kế, không phải số liệu đọc được

Độ tin cậy

  • Số liệu không ghi chú là chép từ code/JSON/CSV/asset của client. "(suy luận)" = suy ra từ cách dùng; giá trị do server gửi lúc chạy (sự kiện, hot update, Firebase RC) chỉ biết schema, trừ khi có trong snapshot.
  • Mỗi use case có cột Evidence là Class::method thật (soát với facts/classes.json bằng tools/jb_gdd_check.py); mở pseudoc/<Class>.c hoặc python tools/jb_condense.py <Class> [method] để đối chiếu.
  • Không đọc được: lịch sự kiện và config live do server gửi, nhóm A/B của người chơi khác, giá store theo vùng, vài file .yaml còn mã hoá.
  • Trang có chữ nghiêng trong menu là trang tạm: GDD của tính năng chưa có (đang viết) nên nội dung lấy từ facts/feature_inventory.json.

Cách cập nhật

  1. Sửa gdd/<Feature>.json (schema gdd/SCHEMA.md) hoặc deep/<Feature>.json (deep/_DEEP_BRIEF.md); level mở khoá trên menu ở gd_config.json → nav_unlock.
  2. Chạy python tools/jb_build_site.py (từ GameDesign/, PYTHONUTF8=1): sinh site_meta/, dựng site/, chèn thiết kế chi tiết, xuất JamBus_GDD.xlsx + JamBus_ThietKeChiTiet.xlsx, icon phần thưởng, rồi soát link/neo/trang rỗng.

Tài liệu chỉ dùng nội bộ cho mục đích nghiên cứu thiết kế.

Tài liệu thiết kế đọc ngược từ client Jam Bus: Sandfall 41.0 (Android, 11/2026) (Cocos2d-x C++, libMyGame.so) · sinh tự động từ GameDesign/gdd/*.json, deep/*.json, appendix/ bằng tools/jb_build_site.py · chỉ dùng nội bộ.
