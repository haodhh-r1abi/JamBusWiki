Mô tả

  • Nút pause ở góc màn chơi mở popup «Pause»: bật/tắt nhạc, âm thanh, rung; Continue; nút thoát level (đi qua chuỗi giữ chân QuitRetention).
  • Có 5 layout biến thể và game chọn theo nhóm AB: bản chuẩn (nhóm 18, 29, 36, 44), bản có nút «Lưu tiến độ» lên tài khoản (template type 0 — gồm nhóm 90 của máy snapshot) và bản thay nút thoát bằng nút Home (type 1/2).
  • Khi pause, toàn bộ adapter của ván nhận onPause và lõi Bus đứng yên.

Tóm tắt thiết kế

CodeAPK Nút pause mở popup «Pause»: nhạc, âm thanh, rung, «Continue» và nút «Quit» (đi qua chuỗi giữ chân); biến thể thêm «Save Progress» hoặc «Home» (.lan OSG_暂停模块). Mở popup gọi pauseGame → mọi adapter onPause, bàn Bus đứng yên.

Code 5 layout biến thể; PauseSystem::getPopupRedream chọn: nhóm AB 18/29/36/44 → bản chuẩn; template type 0 → thêm nút Lưu tiến độ (gọi AccountSystem::onSaveProgress); type 1/2 → nút Home. Live 13/11 Nhóm 90 (máy snapshot) → bản Lưu tiến độ.

Code Nút Home gọi onBackHome, nhưng code chạy breakGame rồi chuỗi «游戏内开始前任务链» (chơi lại) và không qua ô giữ chân — khác hẳn nút thoát.

Luồng người chơi từng bước

  1. Bấm pauseNgười chơiCode
    onClickPauseButton → createWindow (trạng thái 3 nút từ RedWise) + pauseGame.
  2. Bật/tắt âm thanh, rungNgười chơiCode
    Nhạc: RedWise BGM + onMusicSwitch; âm: RedWise SFX + AudioEngine; rung: RedWise + lưu PauseModuleData_2025_05_21.isVibrate.
  3. ContinueNgười chơiCode
    Đóng popup, resumeGame.
  4. Thoát levelNgười chơiCode
    onBeforeQuitTasks → ô giữ chân (QuitRetention).
  5. Lưu tiến độ / HomeNgười chơiCode
    Lưu tiến độ → luồng tài khoản; Home → huỷ ván rồi chạy chuỗi chơi lại (theo code).
  6. Rời levelClientCode
    m8GamePauseAdapter::onQuit → destoryPauseView gỡ nút, popup và texture «OSG_暂停模块_图片资源».

Vận dụng cho game khác

  • Dùng popup pause làm chỗ đặt hành động tài khoản (Lưu tiến độ) cho nhóm AB cụ thể: chỗ người chơi chủ động dừng, ít làm phiền.
  • Tách «thoát» (qua giữ chân, mất mạng) và «chơi lại» rõ ràng; đặt tên nút đúng với hành vi.
  • Nhận định Rủi ro: nút tên «Home» lại chạy chuỗi chơi lại — dễ gây hiểu nhầm và sai số liệu thoát/chơi lại; cần playtest xác nhận.

Mở khóa & điểm vào

Có từ level 1; nút pause được tạo mỗi lần bắt đầu level (m8GamePauseAdapter::onStart → PauseSystem::showButton).

Điểm vào:

  • Nút pause trên HUD (layout «OSG_暂停模块_按钮_暂停», điểm neo «暂停按钮定位点»)

Cách hoạt động

  1. Đầu level m8GamePauseAdapter::onStart gọi PauseSystem::showButton → createButton.
  2. Bấm nút: PauseSystem::onClickPauseButton → createWindow (lấy file theo getPopupRedream, đặt P-音乐按钮状态 / P-音效按钮状态 / P-震动按钮状态 từ RedWise, «暂停页面初始化») và m8GamePauseAdapter::onClickPauseButton → m8GameProtocol::pauseGame → m8GameControl::onPause cho 10 adapter.
  3. Nút nhạc: switchBGMEnable đảo RedWise BGM, báo m8GameProtocol::onMusicSwitch và setMusicEnable.
  4. Nút âm: switchSFXEnable đảo RedWise SFX và AudioEngine::setEnabled.
  5. Nút rung: setVibrateEnable (RedWise::setVibrateEnable; PauseModuleData lưu isVibrate).
  6. Continue: destoryWindow + m8GameProtocol::resumeGame.
  7. Thoát: destoryWindow + m8GameNotify::onBeforeQuitTasks.
  8. Home (biến thể 改为主页): m8GameNotify::onBackHome (setIsRestart, removeRes, breakGame, rồi chuỗi «游戏内开始前任务链»).
  9. Lưu tiến độ (biến thể 添加保存进度): AccountSystem::onSaveProgress.
  10. Kết thúc level: m8GamePauseAdapter::onQuit → PauseSystem::destoryPauseView.
