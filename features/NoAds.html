Tóm tắt thiết kế

APKLive 13/11 SKU adremove.sandfall.01 $9.99 (263.000 ₫ trên store VN). Popup ghi 3 lợi ích: bỏ quảng cáo bắt buộc, bỏ banner dưới, giữ quảng cáo thưởng tuỳ chọn; kèm BONUS 800 coin.

Code Hiệu lực là một cờ a1 trong khối lưu simple_NoAds_system_20250425; m8GameAdapter::showInterAD hỏi isNoADs và bỏ qua mọi interstitial, banner ở màn chính cũng không bật.

Code Popup gợi ý được đẩy vào chuỗi popup lúc mở game và sau game over (Task 免广告模块检查); client đếm tổng lần hiện (a3) và level hiện cuối (a2), quy tắc tần suất nằm trong script Rebolt.

Code Mở từ level 9: SimpleNoAdsAdapter::isActive = cờ bật và level > 8 (getRemoveADsLevelID = 0 không phải cổng thật).

Ảnh cần chụp (4) — 0 ảnh đã gắn

Chụp vào screens/deep_1113/NoAds/ rồi ghi tên file vào flow[].shots.

  • Icon Remove Ads: Icon NoAds trên màn chính
  • Popup khi mở game: Popup Remove Ads! $9.99 + BONUS 800
  • Thành công: Màn 'Permanently ADS-free!'
  • Thất bại: Popup Payment failed

Bảng tổng hợp mọi tính năng đã làm chi tiết: JamBus_ThietKeChiTiet.xlsx.

Mở khóa & điểm vào

SimpleNoAdsAdapter::isActive: cờ bật (+0x18) và level (delegate vfunc +0x18) > 8 → icon/popup từ level 9 (getRemoveADsLevelID = 0 không phải cổng thật). Entry hiện khi chưa mua (SimpleNoAdsSystem::checkEntrance); tần suất popup do script Rebolt quyết định.

Điểm vào:

  • Icon NoAds trên màn chính / trong màn chơi
  • Popup trong chuỗi khởi động (Task 免广告模块检查)
  • Popup sau game over
  • IActvityFeature.showNoADWindow từ tính năng khác

Cách hoạt động

  1. Adapter tạo SimpleNoAdsSystem và đọc khối lưu simple_NoAds_system_20250425 (a1 đã mua, a2 level hiện cuối, a3 tổng lần hiện).
  2. Khi chưa mua, checkEntrance nạp entry Rebolt và đăng ký entry 'NoAds'; lúc mở game và sau game over adapter đẩy Task '免广告模块检查' vào chuỗi popup, task mở popup 'Remove Ads!' (3 lợi ích + BONUS 800 coin + nút $9.99) và tăng bộ đếm.
  3. Bấm mua → m8ActvityAdapter::onPurchaseNoAds → m8PurchaseTool::startPurchase.
  4. Thành công: applyPurchased đặt a1 = true, onGetReward cộng 800 coin, popup 'Permanently ADS-free!', entry bị gỡ.
  5. Từ đó m8GameAdapter::showInterAD bỏ qua mọi interstitial và banner dưới không hiện ở màn chính; quảng cáo thưởng vẫn hoạt động.
  6. Đơn bị treo được khôi phục và hiện kết quả qua showNoADRecoverResult.
