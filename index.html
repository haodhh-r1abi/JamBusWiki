Jam Bus: Sandfall – Game Design Document

Tài liệu thiết kế đọc ngược từ client Jam Bus: Sandfall 41.0 (Android, 11/2026) (Cocos2d-x 3.16, logic C++ trong libMyGame.so, tài nguyên giải mã RC4): mọi tính năng, use case, cấu hình và bảng phần thưởng mà client chứa, kèm tên Class::method làm bằng chứng. Trang có mục Thiết kế chi tiết tóm tắt luồng người chơi, quy tắc, số liệu và cách vận dụng cho game khác.

Danh sách level
Level 1–2000 như người chơi gặp: bàn xe + tranh cát theo nhóm người dùng, biểu đồ xe/màu/cát/độ khó, bảng 297 bàn và 790 tranh.

Level & thống kê
297 file level (chỉ 57 file 上方保留更多空间 được dùng; 42分组/48分组 không dùng) và 381 bảng sinh xe ballData; bảng lọc được toàn bộ.

Tổng quan sự kiện
Sự kiện actlib: activeLv, thời lượng vòng/chu kỳ, vật phẩm thu thập, file config.

SKU trong red_iap.json / shop-v2.json và giá USD mặc định.
🧾
Config mặc định trong APK
JSON/CSV giải mã từ APK làm phẳng thành path = value.
🔤
Text UI

💾

Localization — text UI (48 file .lan)
